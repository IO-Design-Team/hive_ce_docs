# Community tools

!> The tools on this page are built and maintained by third parties. They are not endorsed or vetted by the Hive CE maintainers. Review a tool yourself before you add it to your project.

Packages and tools built around Hive CE. To add one, open a pull request that edits this page.

## xRay

[xRay](https://xrayinspector.dev) by [impaktfull](https://impaktfull.com) is a desktop app for macOS, Windows and Linux that inspects a running Flutter debug build. Its [xray_hive_inspector](https://pub.dev/packages/xray_hive_inspector) package shows Hive CE boxes, including lazy and encrypted boxes, in xRay's Database tab, with optional editing through the app's own box handles.
